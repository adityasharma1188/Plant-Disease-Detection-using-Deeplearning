Plant Disease Detection using Deep Learning

This project is a deep learning-based application designed to detect plant diseases from leaf images. It helps farmers and agricultural users identify diseases quickly and accurately by simply uploading an image of an infected plant leaf.

The system uses *EfficientNetB4*, a powerful pre-trained convolutional neural network, along with transfer learning techniques to classify different plant diseases. The model is trained on labeled leaf image datasets and achieves high accuracy in disease prediction.

A user-friendly *Flask web application* is integrated with the trained model, allowing users to upload images through a browser and instantly receive prediction results.

##  Key Highlights

- Detects multiple plant diseases from leaf images  
- Uses EfficientNetB4 for high performance  
- Built with TensorFlow/Keras and Flask  
- Easy-to-use web interface  
- Fast and accurate predictions  

##  Technologies Used

Python, TensorFlow, Keras, Flask, NumPy, Pandas, HTML, CSS

This project helps in identifying plant diseases efficiently using image classification techniques and deep learning.
